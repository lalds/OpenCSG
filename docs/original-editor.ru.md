# Исходный C# редактор с открытым Linux backend

Подключён оригинальный интерфейс RealtimeCSG к новой библиотеке
`libRealtimeCSG[1_559].so`. Это следующий alpha-этап после отдельного box-прототипа:
используются настоящие CSGModel, CSGBrush, ControlMesh и окно Realtime-CSG.

## Открыть и редактировать

1. В Unity Hub добавить проект `artifacts/OriginalEditor-Fixed` и открыть в Unity
   **2022.3.62f3 на Linux x86_64**.
2. Открыть `Assets/OpenEditorOutput/OriginalEditor.unity` (точный путь также в
   `OriginalEditorScene.txt` в корне подготовленного проекта).
3. Выбрать `Solid` в Hierarchy.
4. Открыть `Tools > OpenCSG > Open CSG editor`.
5. В окне Realtime-CSG использовать режим **Edit**: выбирать и перемещать
   вершины/рёбра/грани исходного brush. Стандартные W/E/R меняют положение,
   вращение и масштаб выбранных элементов/объектов по активному инструменту.

Верхняя панель исходного окна переключает Place, Generate, Edit, Clip, Surfaces.
Generate открывает исходные инструменты создания; Surfaces — настройки
поверхностей и текстур; Clip — исходный инструмент сечения. Для нового простого
примера есть `Tools > OpenCSG > Create demo model`. Он добавляет CSGModel,
Solid и Cutter в текущую сцену и открывает исходное окно редактирования.
Модель и brushes также создаются через `GameObject > Realtime-CSG`.

Окно отдельно доступно в `Window > Realtime-CSG window`. Назначения по умолчанию:
Alt+F1 — Place, Alt+F2 — Generate, Alt+F3 — Edit, Alt+F4 — Clip,
Alt+F5 — Surfaces. Если оконный менеджер Linux перехватывает сочетания,
переключать режимы кнопками окна.

`artifacts/OpenCSG-OriginalEditor.unitypackage` — пакет исходного фронтенда и
двух открытых Linux .so для **чистого Unity 2022.3 проекта**. Он не содержит
старые закрытые Windows/macOS библиотеки и проверочный smoke-script. После
импорта создать пример через Tools/OpenCSG. Вместе с отдельным RecoveryModel
box-прототипом пакет не импортировать: они содержат одинаковые Foundation types.
Пакет предназначен для Linux Editor; сборка backend для других ОС не проверена.

После обновления пакета **полностью перезапустить Unity**: загруженная native
библиотека не заменяется перекомпиляцией C#. Подготовщик проекта отказывается
обновлять проект с `Temp/UnityLockfile`; сначала нужно закрыть его редактор.

Исправления после ручной проверки: временные пустые группы Generate и группы
только с cutters теперь вычисляются как пустое пространство. Пересечение с
пустой группой удаляет геометрию, поэтому такие группы нельзя просто пропускать.
Штатные Wall/Floor/Window/Metal переводятся на шейдер активного pipeline;
в Built-in используется Standard вместо отсутствующей ссылки на shader GUID.
Исправлена также преждевременная остановка конвертации для SRP. Прозрачность
материалов принудительно не включается. Пользовательские материалы не конвертируются.

## Что подключено

- Совместимый C ABI: все 79 различных имён из найденных C# DllImport
  экспортируются. Поведение всего исходного API ещё не сертифицировано.
- Registry дерева: nodes/children/reparenting, проверка циклов, порядок,
  операции, dirty, хранение и обновление BrushMesh, матрицы и bounds.
- Конверсия реального BrushMesh в восстановленное ядро, CSG, подготовка,
  Optimize, исправление стыков и выдача сцены.
- MeshQuery: фильтрация по SurfaceLayers, группировка по render/physics
  параметрам, маска каналов, hashes и части до 65 535 вершин.
- Выбор по видимым CSG-треугольникам, source brush/surface raycast, frustum
  запросы, исходные контуры brushes/граней, UV projection/inverse и UV bounds.
- Простое 2D-разбиение полигонов на треугольники для ConvexPartition.
- Новый исходный режим использует старые C# update/Undo/material/mesh managers;
  нового параллельного менеджера Unity-объектов для него не добавлено.

C# bindings сохранены: new C exports возвращают 32-bit BOOL для стандартного
P/Invoke bool; VertexChannelFlags соответствует исходному byte enum и значениям
0/2/4/8. Две UV-функции принимают Matrix4x4 по значению, третья — по ссылке,
как объявлено в исходном C#. Обе .so лежат рядом; dependency находится по
`$ORIGIN`, а не по абсолютному пути сборочной машины.

При неудачном построении сохраняется предыдущий snapshot. Ошибочный tree
повторно обрабатывается после изменения исходника; другие модели продолжают
обновляться. Ошибка передаётся в Unity Console с userID модели. Изменения
топологии также меняют generation контура. Уничтожение/очистка дерева освобождает
соответствующие кеши. Результаты выдаются с проверкой ёмкостей буферов.

## Что проверено

На Unity 2022.3.62f3 Linux выполнен полный импорт исходных Plugins, открытие
исходного окна и 124 проверки, включая:

- создание/регистрация настоящих CSGModel и CSGBrush через BrushFactory;
- исходный update manager создаёт меши; Foundation выдача даёт объём 6;
- перемещение резака меняет объём на 8, Undo возвращает 6;
- изменение настоящих вершин ControlMesh и пересчёт planes дают объём 10;
- запрос исходного контура возвращает 8 вершин;
- brush picking и выбор по видимым CSG-треугольникам;
- UV bounds и Matrix4x4-by-value P/Invoke; UV совпадает с исходной C# матрицей;
- сохранение сцены и экспорт полного Unity package.

Отдельный ReloadSmoke проверяет восстановление сцены в новом процессе Unity.
Последняя проверка в `artifacts/OriginalEditor-Fixed/OriginalEditorReport.json`:
124 условия, включая штатный Generate Box, изменение высоты, Undo/Redo, Cancel,
операции с пустыми группами и наличие шейдеров/текстур четырёх штатных материалов.
Проверен цилиндр с 16 сторонами: один brush, две целые крышки с центром на оси
или два веера с осевыми вершинами (по CircleSingleSurfaceEnds), объём и Cancel.
ConvexPartition теперь сохраняет выпуклый контур целиком, в обоих направлениях
обхода. Прежняя выдача треугольников создавала лишние brushes и веер к краю.
Уже сохранённые brushes сохраняют прежнюю топологию; цилиндр нужно создать заново.
Невыпуклые контуры по-прежнему разбиваются ear clipping, проверяется сохранение площади.
Проверены обычные сферы и полусферы с 1/2/3 уровнями делений, изменение радиуса
с проверкой кубического отношения объёмов и Cancel. Place сбрасывает старый
hover при смене выделения и Undo. Генераторы при восстановлении после Undo
не регистрируют создание объектов и новые записи Undo повторно.
В native расчёте нормалей убран абсолютный float-порог площади; площадь
вычисляется в double относительно вершины грани. Добавлена проверка корректного
куба с ребром 1e-6, отказа схлопнутой грани и восстановления корректного brush.
Это не означает поддержку всех операций над очень маленькой геометрией:
допуски остальных геометрических проходов остаются прежними.
Во время проверяемого model/generator lifecycle ошибок редактора не было.
Отдельный RenderSmoke выполнен с OpenGL на NVIDIA GTX 1050 Ti, а не nographics:
`OriginalEditorRenderReport.json` содержит 0 розовых пикселей и 31904 пикселя
геометрии; изображение — `OriginalEditorRender.png`. Этот тест подтверждает
отрисовку контрольной сцены Built-in, но не все жесты мышью и render pipelines.
Логи — `artifacts/original-editor-fixed*.log`, `artifacts/original-editor-sphere.log`
и `artifacts/original-editor-cylinder.log`.

Все 27 обычных CTest и 26 native CTest с ASan/UBSan проходят, включая новый
plugin_api. Новый тест проверяет настоящую замкнутую геометрию, C ABI,
union/subtract/intersect, reflection, dirty lifecycle, raycast, UV, outlines,
удаление/переподчинение, отказ некорректной топологии, пустую сцену, prism с
18 halfedges и сохранение/восстановление snapshot при неудачной геометрии.
Проверки через отключаемый Release assert заменены на явные проверки.

## Ограничения alpha

- Уверенно проверен ограниченный домен замкнутых выпуклых brushes и исследованных
  деревьев. Произвольная невыпуклая/вырожденная геометрия и все операции над
  вложенными branches ещё не покрыты; неподдержанный ввод может отклоняться.
- В source outlines все исходные рёбра относятся к видимым. Исходная
  классификация видимых/невидимых линий после CSG ещё не воспроизведена.
- Нормали плоские; smoothing groups ещё не реализованы. Culled mesh helpers
  не возвращают удалённые CSG-фрагменты. Infinite и synchronized/offset сцены
  не включены в проверенную совместимость.
- WorldSpaceTexture интерпретируется в model/tree coordinates: mesh ABI не
  передаёт world transform модели. Полный паритет исходной UV-системы впереди.
- Frustum проверяет объёмы исходных brushes. Разбиение простых 2D полигонов
  выполнено новой ear-clipping реализацией; поведение исходного decomposition
  на всех вырождениях не восстановлено.
- Полная совместимость генераторов, clip, surface tools и сложных реальных сцен
  пока не доказана. Их C# код присутствует и подключён к backend; сценарии нужно
  расширять по результатам ручной работы. Производительность ещё не оптимизирована.

## Пересобрать

```sh
cmake -S native -B /tmp/opencsg-editor-build -G Ninja \
  -DCMAKE_BUILD_TYPE=RelWithDebInfo -DRCSG_BUILD_UNITY_COMPAT_PLUGIN=ON
cmake --build /tmp/opencsg-editor-build -j 4
ctest --test-dir /tmp/opencsg-editor-build --output-on-failure
python3 tools/prepare_original_editor.py \
  --project /tmp/opencsg-original-editor --build /tmp/opencsg-editor-build \
  --unity /home/angel/Unity/Hub/Editor/2022.3.62f3/Editor/Unity
```

Напечатанная команда запускает batch smoke и экспортирует Unity package;
`-quit` не добавлять, поскольку smoke ждёт editor updates и завершает Unity сам.
Для повторного открытия использовать executeMethod
`RealtimeCSG.Recovery.OriginalEditorSmoke.ReloadSmoke`.
В новый проект добавляются только локальные встроенные modules Unity: IMGUI,
UI/UIElements, Physics и прочие необходимые редактору модули. Из внешних
package registries зависимости не скачиваются.
