# Интервалы FixGaps и выравнивание разбиений

Добавлены `native/recovered/gap_intervals.cpp` и интерфейс
`native/include/realtimecsg/recovered_gap_intervals.h`.
Восстановлен сбор локальных интервалов из FixGaps, затем написан отдельный
адаптер, который соединяет его с проверенным SplitTriangleEdgeIndex.
Он дорезает заранее заданную коллинеарную группу по концам соседней группы.
Полный диспетчер FixGaps остаётся впереди. Выбор межbrush-соседа уже восстановлен
в [отдельном модуле согласованных интервалов](gap-neighbors.ru.md).

Источник — Mach-O x86_64, SHA-256
`26789e84b0c11376582662bf1d53ed21a65c68d57449efb607070b266cb61a7d`.

## Восстановленный сбор интервалов

Участок `0x384ce..0x387b3` обходит vector<TriangleEdgeIndex> BrushEdge по +24.
Прямая задаётся единичным направлением по BrushEdge+80 и точкой по +92.
Для каждого конца ребра из worldPositions вычисляются:

```text
t = dot(point - origin, direction)
projected = origin + direction*t
distanceSquared = |projected - point|²
```

Оба конца должны иметь `distanceSquared < 1.0000000116860974e-7f`
(константа `0x3c574`); сравнение строгое. Порядок float-операций сохранён.
Публичный интерфейс дополнительно проверяет единичность/конечность прямой
и индексы до обхода. Неконечные координаты, дающие NaN в проверке расстояния,
не проходят сравнение, как в машинном коде.

Если twin текущего ребра уже есть среди **принятых** интервалов, ребро пропускается.
Это не общее удаление повторов: повтор одного и того же handle сохраняется.
Скрытые triangles и нулевая длина не фильтруются на данном этапе.

Interval занимает 24 байта:

| Смещение | Значение |
| --- | --- |
| +0/+4 | Нижняя/верхняя координата вдоль прямой, float |
| +8/+12 | Индексы соответствующих vertices |
| +16 | Исходный TriangleEdgeIndex |
| +20 | Бит обратного направления |
| +21..+23 | Padding, не определён оригинальным сборщиком |

Концы сортируются по проекции. Бит направления равен triangle.flags bit 4,
инвертированному при перестановке концов. Коллектор не меняет меш.
Переносимая запись обнуляет padding; с оригиналом сравниваются 21 определённый байт.

## Новый адаптер дорезания

`alignGapIntervals` получает явные local/foreign группы и общую прямую.
Он собирает интервалы, ищет концы foreign-группы строго внутри локальных
и вызывает восстановленное разбиение. Локальные BrushEdge-списки обновляются
самим SplitTriangleEdgeIndex. После каждого разрезания интервалы собираются
заново из актуальной геометрии.

Условия внутренней точки взяты из `0x38ad3..0x38b23`:

```text
pointT - lower > 0.00390625f
pointT - upper < -0.00390625f
```

Вес перед вызовом SplitTriangleEdgeIndex равен `(pointT-lower)/(upper-lower)`
по `0x393fb..0x3942c` и `0x3966e..0x396a5`. Мировая точка берётся с вершины
foreign-меша, локальная позиция вычисляется по переданной world-to-local матрице.
Допуск 1/256 дан в мировых единицах, поскольку направление прямой единичное.

Это **новая организация вызовов**, а не полная декомпиляция FixGaps.
Исходная функция обновляет собственный временный vector и обрабатывает
согласованные интервалы с учётом четырёх окружающих surfaces. В адаптере
пока реализовано только согласование геометрического разбиения явно заданной
группы. Foreign-геометрия сохраняется, затем можно выполнить проход в обратную сторону.

Локальная изменяемая группа должна содержать уникальные handles, принадлежащие
переданному sourceIndex. Есть лимит числа разрезаний; буферы фиксированной ёмкости.
Отдельное разрезание проверяет вход до мутации, но ошибка на последующем
разрезании может оставить уже выполненную часть работы. Повторный вызов для
согласованных групп не добавляет вершин.
Сборщик квадратичный из-за проверки twins; повторный сбор после каждого разреза
в исследовательском адаптере также требует дальнейшей оптимизации.

## Эталон сборщика без изменения кода оригинала

`tools/compare_recovered_gap_intervals.py` исполняет оригинальный FixGaps
и его vector<Interval> helpers на Linux x86_64. Подготовлен один связанный
foreign BrushEdge с пустым списком triangle edges. Оригинал собирает локальные
интервалы и по `0x387cf → 0x398f3` пропускает сопоставление/разрезание.

Байты исходного кода не патчатся. Обёртки new/delete выделяют память через Linux
libc, заполняют её `0xcc` и считывают перед освобождением. Так наблюдаются
определённые поля временных интервалов. Допустимые handles теста отличаются от
маркера неиспользованной ёмкости. Padding исключён из сравнения.
Это проверка **сборщика**, а не всего изменения состояния FixGaps:
оригинальный пролог также сбрасывает brushEdges, переносимый чистый сборщик этого не делает.

При seed 1559: 5 000 входов, 84 500 интервалов, расхождений нет.
В 3 774 случаях исходный временный буфер рос за начальные восемь записей.
Покрыты осевые/наклонные прямые, обратные направления, близкие к допуску
отклонения, дубли handles, twins и произвольные flags, включая скрытые грани.

## Сравнение с полным вызовом FixGaps в ограниченной задаче

`tools/compare_gap_alignment.py` запускает также исходные SplitTriangleEdgeIndex,
AddWorldVertex, TransformToBrushSpace и TriangleNormal. Теперь foreign-группа
содержит разрезанные рёбра, и выполняется полный оригинальный FixGaps.
Необходимые части manager, поверхности и identity transforms заданы явно.
Импорты malloc/free/memcpy/bzero привязаны к Linux libc; исходные пути роста
triangle/vertex/BrushEdge capacities исключены запасом буферов.

На 200 парах замкнутых тетраэдров с разным разбиением одного общего отрезка
сравниваются полученные сегменты, количества вершин/треугольников, объём,
площадь и замкнутые взаимные triangle twins. Результаты совпали: каждая
реализация добавила суммарно 924 вершины. Границы сегментов также независимо
проверяются по заранее выбранным координатам разрезания.
**Эквивалентность выбора межbrush ссылок и нормалей этим сравнением не заявляется.**

Перед исполнением проверяется SHA-256, страж статической инициализации подготовлен.
Код RX, данные RW; RWX-страниц, инициализаторов Mach-O и Unity нет.
Пути исключений не поддерживаются. Оба скрипта запускаются отдельными процессами.

## Проверки C++ и воспроизведение

```sh
cmake --build /tmp/realtime-csg-recovery/build
ctest --test-dir /tmp/realtime-csg-recovery/build --output-on-failure
python3 -B tools/compare_recovered_gap_intervals.py --library /tmp/realtime-csg-recovery/build/librealtimecsg_recovered_geometry.so --cases 5000
python3 -B tools/compare_gap_alignment.py --library /tmp/realtime-csg-recovery/build/librealtimecsg_recovered_geometry.so --cases 200
```

Новый CTest связывает сборщик и разбиение: на двух закрытых тестовых мешах
общая группа сначала имеет один сегмент с одной стороны и три с другой.
Адаптер находит две недостающие точки и получает одинаковые разбиения.
Проверяются twins, концы рёбер, сохранение foreign-меша, объём/площадь,
повторный и обратный вызовы. Есть проверка другого локального пространства
с масштабом/переносом, точного порога 1/256 и частичного выполнения при лимите.
Самостоятельно проверяются ошибки буфера, некорректные handles и native-правила дублей.
Проверки выполняются также ASan/UBSan с отключённым leak detection.

## Что остаётся

Обход BrushEdge-соответствий и проверки manager теперь перенесены
в [диспетчер FixGaps](gap-dispatch.ru.md). Выбор по видимости/направлению/нормалям уже
перенесён для согласованных групп; он отдельно проверяется без разрезаний.
Обновление временных интервалов исходного FixGaps во время разрезаний
восстановлено в [fixGapGroup](fix-gap-group.ru.md) с совместным выбором соседей.
Подготовка самих связей, полная обработка неоднозначных стыков и дальнейшая
сварка/очистка ещё впереди.
Прежние 740 объёмных тестов остаются проходящими, но этот адаптер пока не
включён в них как глобальное автоматическое исправление мешей.
Согласованные сегменты одной заданной группы не доказывают manifold всего результата.
