# Выбор соседей в FixGaps

В `native/recovered/gap_neighbors.cpp` перенесён выбор межbrush-ссылок
для уже согласованных интервалов. Интерфейс —
`native/include/realtimecsg/recovered_gap_neighbors.h`.
Источник — тот же Mach-O x86_64 версии 1.559, SHA-256
`26789e84b0c11376582662bf1d53ed21a65c68d57449efb607070b266cb61a7d`.

## Восстановленные правила

Пролог FixGaps сбрасывает все три `triangle.brushEdges` в `{-1, 0xffffffff}`.
Переносимая функция `resetGapNeighbors` выполняет этот сброс отдельно:
при последовательной обработке нескольких соседних брашей ссылки нужно
сбрасывать один раз перед всем проходом.

Участок `0x38b45..0x393cf` обрабатывает совпавшие интервалы.
Для обеих границ требуется строгое `abs(foreign-local) < 1/256`.
Пусть L — локальное ребро, LT — его twin, F — foreign-ребро, FT — его twin.
Бит направления интервала учитывает перестановку концов и `flags & 0x10`.

| Направления интервалов | Кандидат для L | Кандидат для LT |
| --- | --- | --- |
| Совпадают | FT | F |
| Отличаются | F | FT |

Каждая пара рассматривается только при `flags & 8` у обоих треугольников.
L и LT могут независимо получить или не получить соседа.
Нормаль берётся из `sourcePlanes[triangle.surfaceIndex].normal`.
При `flags & 0x10` инвертируются знаковые биты трёх float-компонентов.
Это не нормаль из cornerNormals и не векторное произведение вершин;
нормализация или дополнительное преобразование здесь не выполняются.
Источник вспомогательного чтения — `TriangleNormal`, `0x37fb6..0x38095`.

При пустой текущей ссылке кандидат записывается сразу.
Если ссылка уже есть, вычисляются в float с порядком `(x+y)+z`:

```text
candidateScore = dot(localNormal, candidateNormal)
incumbentScore = dot(incumbentNormal, localNormal)
replace only if candidateScore > incumbentScore
```

При равенстве или unordered-сравнении с NaN остаётся текущая ссылка.
Поэтому порядок обхода соседних брашей существенен.
Для отсутствующего/неактивного manager-узла TriangleNormal возвращает нулевой
вектор: существующая неотрицательная ссылка заменится только при score > 0.
Переносимый интерфейс моделирует этот случай явно.

## Граница реализации

`matchGapNeighbors` — **новый диспетчер явных групп** поверх восстановленных
правил выбора. Он собирает локальные интервалы с native-устранением twins,
но foreign-handles посещает по одному, без устранения twins, в исходном порядке.
При повторных вызовах существующие ссылки участвуют в выборе.
Проверки handles и surfaces на активных узлах выполняются до записи;
оригинал обращается к части этих массивов без проверки.

Буферы manager и planes принадлежат вызывающему коду. Неподходящие по концам
интервалы пропускаются: разрезание здесь не выполняется.
Можно сначала вызвать `alignGapIntervals`, затем сопоставление и `connectGaps`.
Эта последовательность не доказывает побайтовую эквивалентность всего FixGaps
с разрезаниями. Исходное обновление временного vector<Interval> теперь перенесено
в [совместном проходе fixGapGroup](fix-gap-group.ru.md), отдельно проверенном
сравнением полных буферов после разрезаний.
Общий обход BrushEdge-связей, фильтр направлений прямых, подготовка этих связей
и дальнейшая сварка/оптимизация также не входят в этот модуль.

## Проверка на оригинальном машинном коде

`tools/compare_gap_neighbors.py` вызывает полный неизменённый FixGaps
через ранее подготовленный Linux-стенд. Вход — согласованная общая группа
тетраэдров с 1–7 foreign-брашами. Manager содержит реальные sourcePlanes;
cornerNormals намеренно заданы другими значениями.

При seed 1559 выполнено 5 000 случаев с 20 068 foreign-брашами.
Сравниваются **все байты всего буфера треугольников**, включая поля вне ссылок,
и неизменность foreign-треугольников и локальных вершин.
Расхождений нет; в итоговых локальных мешах выбрано 4 684 ссылки.
Покрыты произвольные flags, обе ориентации, скрытые треугольники, разные
порядки handles, повторы, конкурирующие нормали, равенства, NaN и бесконечности.
Разрезаний этот эталон не требует: отдельно они проверяются прежним стендом.

Девятый CTest проверяет все 256 сочетаний видимости/разворота четырёх граней,
выбор более сильной нормали, сохранение при равенстве/NaN, нулевой fallback,
точный порог совпадения, ошибки входа до записи и обратный ConnectGaps.
Предыдущий CTest интервалов расширен цепочкой «два разрезания → три сегмента →
выбор соседей → обратные ссылки» на замкнутых тетраэдрах.

```sh
cmake --build /tmp/realtime-csg-recovery/build
ctest --test-dir /tmp/realtime-csg-recovery/build --output-on-failure
python3 -B tools/compare_gap_neighbors.py --library /tmp/realtime-csg-recovery/build/librealtimecsg_recovered_geometry.so --cases 5000
```
