# Внешний обход FixGaps

`native/recovered/gap_dispatch.cpp` связывает восстановленный внутренний
`fixGapGroup` с внешним обходом BrushEdge-связей. Интерфейс находится в
`native/include/realtimecsg/recovered_gap_dispatch.h`;
C-функция — `rcsg_recovered_fix_gaps`.

Источник — Mach-O x86_64 RealtimeCSG 1.559, SHA-256
`26789e84b0c11376582662bf1d53ed21a65c68d57449efb607070b266cb61a7d`.
Внешний обход: `0x380ca..0x384ce`, возврат к следующей связи/группе:
`0x398f3..0x39944`. Подготовка исходных связей здесь не восстанавливается.

## Восстановленный порядок

Сначала сбрасываются все локальные triangle.brushEdges, один раз за вызов.
Затем обходятся source-группы по порядку и connections каждой группы
по порядку хранения. Повторы связей сохраняются.
Для каждой связи:

1. Пропустить отрицательный brush ID и ID за пределами manager.
2. Проверить metadata.kind == 3, наличие node и совпадение node.index с ID.
3. Прочитать направление соответствующей foreign BrushEdge-группы.
4. Пропустить недостаточно параллельные направления.
5. Пропустить null mesh, отсутствующий source record или нулевой plane count.
6. Заново собрать локальные интервалы из актуальной группы и выполнить
   внутренний проход с разрезаниями и выбором соседей.

Повторный сбор между разными связями соответствует оригиналу. Внутри одной
связи сохраняются собственные временные интервалы, включая native reverse-биты
после разрезаний. Разрезание обновляет все затронутые source-списки; поэтому
позднее посещаемые группы используют актуальные handles.

Фильтр направлений использует float с порядком `(x+y)+z`:

```text
alignment = abs(dot(local.direction, foreign.direction))
skip if alignment <= 0.9999899864196777f
```

Равенство порогу пропускается. Отрицательное параллельное направление
принимается за счёт abs. Исходный `ucomiss; jae` не пропускает unordered
сравнение с NaN; этот случай тоже сохранён и проверен на оригинальном коде.
Foreign origin при фильтрации не используется: проверка фактических концов
далее идёт относительно локальной прямой.

## Явный manager вместо глобального состояния

`GapDispatchNode` содержит ранее введённый `GapNeighborBrushView`, массивы
source-списков и прямых, sourceCount, nodeKind и sourceRecordValid.
Отсутствующий node представляется несовпадающим/отрицательным nodeIndex.
sourceRecordValid моделирует наличие sourceMeshIndex внутри массива поверхностей.
Пустой mesh у существующего node — отдельный случай.

Нормаль ранее выбранного соседа читается по правилам TriangleNormal:
проверка nodeKind там не добавляется. Отсутствующий source record даёт
нулевую нормаль. Все массивы принадлежат вызывающему коду.
Массивы source/line/connection должны согласовываться по индексам.
В используемых локальных группах прямая должна быть конечной и единичной,
mutable-handles уникальны, буферы foreign не должны пересекаться с local.

Переносимый интерфейс проверяет индексы foreign-групп на активных узлах,
которые оригинал разыменовывает без проверки. Ошибка возвращает -1.
Есть общий лимит разрезаний на весь вызов, а не отдельный лимит на группу.
При нехватке ёмкости/лимита возвращается -2; сброс ссылок и ранее выполненные
разрезания/записи могут сохраниться. Это дополнительное ограничение нового API.

## Сравнение всего вызова

`tools/compare_fix_gaps.py` строит для оригинала настоящие manager metadata,
node-указатели, массивы surface records и BrushEdge по 104 байта.
У каждого замкнутого тетраэдра три группы — вдоль трёх рёбер из одной вершины.
Каждая группа независимо дорезается 0–2 раза. Порядки handles и связей
перемешиваются, встречаются повторы и связи с другой группой.
Заданы произвольные visibility/reverse flags и source normals.
Начальные ссылки заполняются заведомо другим значением для проверки сброса.

Для foreign-узлов проверяются семь состояний: valid, отсутствующий node,
другой kind, несовпадающий index, null mesh, отсутствующий source record,
нулевое число planes. В направлениях проверяются положительные/отрицательные,
перпендикулярные, точный порог, соседние float выше/ниже порога и NaN.

При seed 1559:

| Показатель | Результат |
| --- | --- |
| Входы с тремя группами | 2 000 |
| Посещения connections | 32 978 |
| Новые вершины в каждой реализации | 2 898 |
| Расхождения полных буферов меша | 0 |
| Ошибки внутренних twins, объёма или площади | 0 |

Побайтово сравниваются все triangle/vertex/world-position/world-lookup буферы
и все три source-буфера, включая неиспользуемую ёмкость. Также сравниваются
количества элементов, неизменность foreign-буферов и геометрические инварианты.
Код оригинала не патчится, SHA-256 проверяется перед исполнением.
Фикстуры имеют общий мир и единичные world-to-local матрицы; запас ёмкости
исключает native пути роста triangle/vertex/BrushEdge-списков.

Десятый CTest проверяет три последовательных группы, обновление их handles,
общий лимит и частичное выполнение, сброс старых ссылок, фильтрацию узлов,
точный порог направлений/NaN и безопасную ошибку на неверном source index.
Все десять CTest проходят в обычной сборке и с ASan/UBSan
(`ASAN_OPTIONS=detect_leaks=0`).

```sh
cmake --build /tmp/realtime-csg-recovery/build
ctest --test-dir /tmp/realtime-csg-recovery/build --output-on-failure
python3 -B tools/compare_fix_gaps.py --library /tmp/realtime-csg-recovery/build/librealtimecsg_recovered_geometry.so --cases 2000
```

## Что ещё требуется

BrushEdge-группы, их прямые и surface references уже создаёт восстановленный
[FindBrushEdges](brush-edges.ru.md). Triangle-edge lists заполняет
[CleanUpBrushEdges с объединением конфликтующих пар](brush-edge-cleanup.ru.md).
Разрешение surface references в connections требует дальнейшей интеграции; восстановленный
[FindConnections](connections.ru.md) сохраняет неожиданную macOS-адресацию,
которая может дать self references. В тестах диспетчера connections пока
задаются явно и между независимыми мешами. Внешний ABI оригинального
Unity-плагина этим интерфейсом ещё не реализован.
Обратный ConnectGaps остаётся отдельным вызовом, как в исходном manager-проходе.
Сварка, решения Optimize и проверка сложных сцен требуют дальнейшей работы.
Сравнение на ограниченных фикстурах не доказывает manifold произвольного CSG.

Теперь [исследовательский адаптер сцены](convex-gap-repair.ru.md) создаёт
connections по реальным foreign IDs, вызывает FixGaps до обхода без разрезаний
и затем ConnectGaps. Сам низкоуровневый dispatcher сохранён без изменений.
