# FindBrushEdges: группы полурёбер и ссылки на поверхности

В `native/recovered/brush_edges.cpp` перенесён FindBrushEdges
(`0x20b53..0x215b5`), интерфейс —
`native/include/realtimecsg/recovered_brush_edges.h`.
Источник — Mach-O x86_64 RealtimeCSG 1.559, SHA-256
`26789e84b0c11376582662bf1d53ed21a65c68d57449efb607070b266cb61a7d`.

## Что функция получает и создаёт

Вход — один полигон исходного halfedge-меша, нормаль его плоскости,
массив плоскостей другого браша и его AABB, уже выраженные в локальных
координатах этого меша. Дополнительно передаются ID другого браша и индекс
рассматриваемой его поверхности, а также local-to-tree матрица.
Оригинал получает матрицу через глобальный manager.

Выход — дополнение общего списка BrushEdge-групп и запись индексов групп
в оба полуребра каждой принятой пары. Тем самым поле EdgeLink+4,
ранее обозначенное `unidentified_04`, подтверждено как source group index.
Перед подготовительным проходом оно должно быть инициализировано в -1.
`previousEdge` и вся геометрия/топология остаются неизменными.

В исходной BrushEdge размером 104 байта:

| Смещение | Содержимое |
| --- | --- |
| +0 | vector пар (foreign brush ID, foreign surface index) |
| +24 | vector triangle-edge handles, здесь не заполняется |
| +48 | vector разрешённых межгрупповых связей, здесь не заполняется |
| +72/+76 | Индексы двух локальных соседних surfaces |
| +80/+92 | Направление и точка прямой в пространстве дерева |

Переносимый `BrushEdgeGroupView` содержит только используемые этой функцией
поля и явную ёмкость массива ссылок. Это не исходная 104-байтовая структура
и не внешний ABI Unity-плагина.

## Отбор рёбер

Направление сначала равно `cross(localNormal, foreignNormal)`.
Если его float lengthSquared строго меньше `9.999999747378752e-6f`,
функция возвращается. Направление умножается на линейную 3×3 часть
local-to-tree матрицы, затем нормализуется в double с возвратом float.
Несмотря на имя `TransformNormalToTreeSpace` (`0x4b12..0x4ba6`), здесь
используется обычная линейная матрица, без inverse transpose.

Рёбра обходятся в порядке `polygon.firstEdge`, затем `nextEdge`, edgeCount раз.
Концы берутся из edge.vertexIndex и twin.vertexIndex. Для каждого конца:

* расстояние `dot(foreignNormal, point)-distance` должно лежать строго
  между `-0.0006000000284984708f` и `+0.0006000000284984708f`;
* координаты должны пройти AABB с допуском `9.999999747378752e-5f`:
  `min-point < epsilon`, `max-point >= -epsilon`.

В AABB должны входить **оба конца**, пересечения сегмента с ним недостаточно.
Исходный AABB передаётся шестью float в порядке minX,maxX,minY,maxY,minZ,maxZ.

Для каждой плоскости foreign-массива ребро отклоняется, только если **оба**
конца находятся снаружи на расстоянии строго больше plane tolerance.
Здесь нет полного клиппинга сегмента по всем плоскостям.
Для принятого ребра его первая конечная точка преобразуется в tree-space
с добавлением translation (`TransformToTreeSpace`, `0x4c84..0x4d2a`).

## Выбор и переиспользование группы

Пара surfaces берётся из текущего полигона и полигона twin-ребра.
Сначала проверяются source indices двух полурёбер:

* одинаковый назначенный индекс используется напрямую;
* если назначена только одна сторона, используется её индекс;
* если обе стороны не назначены либо имеют разные назначенные индексы,
  выполняется поиск по геометрии существующих групп.

При поиске нужны та же неупорядоченная пара surfaces,
`abs(dot(existingDirection,newDirection)) > 0.9999899864196777f`
и квадрат расстояния существующей точки до новой прямой строго меньше
`1.0000000116860974e-7f`. Если группы нет, создаётся новая.
Её point сохраняется от первого принятого ребра, направление — от текущей
пары плоскостей. Существующие группы при переиспользовании не переписываются.

В выбранную группу добавляется пара (foreignBrush,foreignSurface),
если такой пары ещё нет. Индекс группы записывается в обе EdgeLink-записи.
Ни triangle-handle lists, ни resolved connections этот проход не создаёт.

## Проверка исходным машинным кодом

`tools/compare_brush_edges.py` исполняет неизменённую функцию и её helpers
на Linux x86_64. SHA-256 проверяется до загрузки. Код RX, данные RW;
добавочные диапазоны копируются без изменения байтов. new/delete, bzero
и memmove привязаны к Linux libc. Матрица задаётся в manager transform record.

У этого внутреннего символа компилятор специализировал ABI: исходная
сигнатура с `Plane const&` сохранилась в имени, но нормаль фактически приходит
отдельными scalar float в xmm0..2, polygon index — в edx. Это подтверждено
инструкциями вызывающего Categorize по `0x204df..0x20519`.
AABB занимает 24 байта стека, указатель выходного vector следует за ним.
Прямой ctypes-вызов по исходной деманглированной сигнатуре был бы неверен.

На seed 1559 проверены:

| Показатель | Результат |
| --- | --- |
| Меши | 5 000 |
| Вызовы оригинала | 19 930 |
| Итоговые группы | 6 495 |
| Итоговые ссылки на поверхности | 9 896 |
| Расхождения | 0 |

Фикстуры — замкнутые двусторонние полигоны с последовательными коллинеарными
полурёбрами. Есть разные параллельные линии с той же парой surfaces,
повторные вызовы/ссылки, непустые и частично назначенные индексы сторон,
разные индексы двух сторон, граничные расстояния до плоскости,
ограничение AABB и отсев остальными плоскостями, параллельные нормали,
случайные матрицы с масштабом, сдвигом и смешиванием координат.
Исходная топология и все буферы меша сравниваются целиком;
surfaces/line records — побайтово, ссылки — в исходном порядке.
Неиспользуемые triangle/connection vectors оригинала остаются пустыми.

Внешний vector<BrushEdge> заранее имеет запас ёмкости; путь его роста
не исполняется. Внутренние vectors ссылок оригинала выделяются и растут
обычным образом. Переносимая версия использует заранее выделенные буферы.
Ошибка ёмкости может оставить изменения от ранее обработанных рёбер;
для текущего нового ребра ёмкость проверяется до записи source indices.

Одиннадцатый CTest проверяет группировку двух коллинеарных сегментов,
различение параллельных прямых, оба source indices, дедупликацию ссылок,
порог плоскости, AABB, отбрасывание остальными плоскостями, local-to-tree,
ошибки ёмкости и некорректный существующий индекс.

```sh
cmake --build /tmp/realtime-csg-recovery/build
ctest --test-dir /tmp/realtime-csg-recovery/build --output-on-failure
python3 -B tools/compare_brush_edges.py --library /tmp/realtime-csg-recovery/build/librealtimecsg_recovered_geometry.so --cases 5000
```

## Следующий участок

Заполнение triangle-edge lists и удаление пустых групп уже перенесены для
[тегов с объединением конфликтующих пар](brush-edge-cleanup.ru.md).
[FindConnections](connections.ru.md) уже перенесён, но в macOS-коде обнаружена
адресация manager по текущему brushIndex, способная создавать self references.
Для подключения к диспетчеру FixGaps эта особенность требует отдельного решения.
Вызовы FindBrushEdges из полного
Categorize, transforms foreign planes/AABB и общий broad phase ещё не перенесены.

В [исследовательской подготовке выпуклых мешей](convex-mesh-preparation.ru.md)
FindBrushEdges теперь вызывается после категоризации в общем пространстве,
до Create/Optimize. Это новая организация, а не восстановленный исходный Categorize.
