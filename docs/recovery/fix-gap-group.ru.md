# FixGaps: разрезания и выбор соседей в одном проходе

В `native/recovered/gap_neighbors.cpp` добавлен `fixGapGroup` с C-интерфейсом
`rcsg_recovered_fix_gap_group`. Это восстановленный внутренний проход FixGaps
для одной уже установленной связи коллинеарных BrushEdge-групп.
В отличие от прежнего `alignGapIntervals`, здесь после разрезаний сохраняются
исходные временные записи интервалов и сразу выполняется выбор соседей.

Источник — Mach-O x86_64 RealtimeCSG 1.559, SHA-256
`26789e84b0c11376582662bf1d53ed21a65c68d57449efb607070b266cb61a7d`.
Код обновления после нижнего разреза: `0x393fb..0x39669`;
после верхнего: `0x3966e..0x398d0`.

## Порядок обработки

1. Собрать локальные интервалы по уже восстановленным правилам.
2. Посещать каждый foreign-handle в исходном порядке, без устранения twins.
3. Для каждого локального интервала сначала проверить нижнюю foreign-границу
   строго внутри с допуском 1/256, затем верхнюю.
4. При разрезании вызвать SplitTriangleEdgeIndex, добавить один интервал для
   возвращённого handle и обновить старый по изменённым вершинам.
5. После каждого разрезания повторить обработку того же foreign-handle
   с начала локального списка.
6. Для совпавших границ выполнить восстановленный выбор соседей по видимости,
   направлению и нормалям, сохраняя ранее выбранные ссылки между вызовами.

Вес разрезания: `(foreignBoundary-localLower)/(localUpper-localLower)`.
Мировая точка берётся с foreign-вершины, локальная вычисляется переданной
world-to-local матрицей. Обновление интервалов проецирует фактические вершины
из worldPositions; это не простое копирование foreign-параметра.

## Особенность бита направления

Оригинал не пересчитывает `Interval.reverse` после изменения геометрии.
Старый интервал сохраняет свой бит. Новый интервал создаётся через
`vector<Interval>::resize` с нулевой инициализацией и остаётся с `reverse=0`.
Это подтверждается `resize`/`__append` по `0x39c1a..0x39ea8`, включая
обнуление всех 24 байт новой записи.

Сортировка концов и обновление vertex IDs при этом выполняются.
Для старого интервала после верхнего разреза начальный порядок чтения концов
обратный; это также сохранено, включая поведение при равных проекциях.

Повторный сбор интервалов из готовой геометрии может дать другой reverse-бит
и другие межбрашевые ссылки. Поэтому прежняя цепочка
`alignGapIntervals → matchGapNeighbors` остаётся отдельной новой организацией
вычислений. Она не заменяет восстановленный `fixGapGroup` при сравнении
всего состояния с оригиналом.

## Проверка оригинальным FixGaps

`tools/compare_fix_gap_group.py` выполняет полный неизменённый оригинальный
FixGaps и сравнивает его с последовательными вызовами `fixGapGroup`.
Перед вызовами переносимой реализации ссылки сбрасываются один раз.

Входы — замкнутые тетраэдры с независимо разрезанным общим ребром:
0–5 исходных разрезаний у каждого браша, 1–4 foreign-браша,
перемешанные порядки handles, произвольные flags и source normals,
равные нормали и NaN. Фикстуры повёрнуты на все три оси, имеют положительное
или отрицательное направление общей прямой и целочисленные переносы.
World-to-local матрицы в этом сравнении единичные.

При seed 1559:

| Показатель | Результат |
| --- | --- |
| Случаи | 2 000 |
| Foreign-браши | 5 080 |
| Новые вершины в каждой реализации | 10 760 |
| Расхождения полных буферов | 0 |
| Ошибки замкнутых twins, объёма или площади | 0 |

Побайтово сравниваются triangle records, включая межбрашевые ссылки и
неизвестные поля, vertex records, worldPositions, worldVertexLookup и source
handles, а также количества элементов. Включена неиспользуемая ёмкость
подготовленных буферов. Foreign-буферы должны оставаться неизменными.
Геометрические инварианты дополнительно проверяются независимо от сравнения.
Запас ёмкости исключает исходные пути роста triangle/vertex/BrushEdge буферов.
Временный vector<Interval> оригинала выделяется и растёт обычным образом.

CTest интервалов дополнен точным примером с двумя разрезаниями и шестью
ожидаемыми ссылками, полученными исполнением оригинала. Этот пример различает
сохранение native reverse-битов и повторный сбор интервалов.
Проверяются нулевой лимит разрезаний и частичное выполнение при лимите один.
Все девять CTest проходят в обычной сборке и с ASan/UBSan
(`ASAN_OPTIONS=detect_leaks=0`).

```sh
cmake --build /tmp/realtime-csg-recovery/build
ctest --test-dir /tmp/realtime-csg-recovery/build --output-on-failure
python3 -B tools/compare_fix_gap_group.py --library /tmp/realtime-csg-recovery/build/librealtimecsg_recovered_geometry.so --cases 2000
```

## Оставшиеся границы

Связь групп задаётся вызывающим кодом. Общий обход manager и фильтр направлений
теперь реализованы в [отдельном диспетчере](gap-dispatch.ru.md).
Подготовка BrushEdge-соответствий ещё не восстановлена. Ссылки не сбрасываются внутри группы,
и обратный ConnectGaps вызывается отдельно после обработки всех связей.
Одинаковые результаты ограниченных фикстур не доказывают manifold всей CSG-сцены.

Переносимый API использует фиксированные буферы, проверяет индексы и запрещает
повторные mutable-handles. Есть лимит разрезаний; ошибка после уже выполненной
части работы может оставить разрезания и ссылки в меше. Это исследовательский
интерфейс, не готовый внешний ABI Unity-плагина.
